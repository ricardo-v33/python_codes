# Theoretical Research
Data analysis and data visualization codes created through the NOIRLab Astro Data Lab JupyterHub environment pertaining to the study of shape and motion of open star clusters. These programs are cross-comparisons of stellar parameter measurements from our own Gaia Data Release 3 datasets to those of *Hunt and Reffer (2023)*. Pipelines were also created for efficient recalls of calculation and plotting functions as seen in the Exercise/Project notebooks.
