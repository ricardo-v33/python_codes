# Theoretical Research
Data analysis and data visualization codes created through the NOIRLab Astro Data Lab JupyterHub environment pertaining to the study of shape and motion of open star clusters. These programs are cross-comparisons of stellar parameter measurements from our own Gaia Data Release 3 datasets to those of *Hunt and Reffer (2023)* (HR2). Pipelines were also created for efficient recalls of calculation and plotting functions as seen in the Exercise/Project notebooks.

`Project_4-Cleaned.ipynb` finds the stars common between our datasets for multiple clusters and the literature. This allows us to observe how the cluster shapes differ in position and velocity space and other stellar parameter space since our cluster was selected by eye and HR2's was selected via a machine learning tool HDBSCAN. Comprehensive comparisons of these are at the end of the notebook. `Project_5_Pipelined.ipynb` performs Principal Component Analysis (PCA) on datasets for the M67 and Blanco 1 clusters in efforts to find the most effective parameters to isolate the cluster amongst field stars. The resulting parameters and the PCA dataset can then be given to a machine learning tool to more precisely assign cluster members with a focus on low-mass stars. PCA will be further explored with machine learning in the future. `shape-motion.ipynb` analyzes the 3-dimensional shape of these clusters in heliocentric position and velocity space, and points out stars that appear to have drastically different parameter values than their counterparts in the same cluster. This leads to a demonstration of how the 3D shape of the cluster elongates for more distant clusters and their fainter stars.

Future work will consist of developing new methodologies to better constrain low-mass star membership of open clusters and observe its effectiveness in maintaining true geometrical representations of the positions and velocities.
